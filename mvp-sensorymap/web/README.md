# SenseScape Web App

Browser-based version of SenseScape for viewing sensory experiences on a map.

## Running the App

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser to:
```
http://localhost:3000
```

## Features

- **Interactive Map**: Clean, light-colored map with emotion pins
- **Quick Add Feeling**: Floating action button to quickly add your feelings at any location
- **Sensory Logs**: View and create detailed sensory experiences
- **Location Previews**: See aggregated sensory data for locations
- **AI Predictions**: Get predictions about how locations might feel
- **Daily History**: View summaries of your sensory journey

## Design

The app features a clean, minimal design inspired by modern mobile map applications:
- Light blue-grey map tiles
- Orange accent color (#FF9500) for primary actions
- White UI elements with subtle shadows
- Clean typography and spacing

## Mock Data

All features work with mock data - no backend required for demo purposes.
